# 제약 바이오 EBRS 목업 UI

제약·바이오 원료의약품 제조용 전자 배치 기록 시스템(EBRS)의 클릭 가능한 목업입니다. `index.html` 하나를 브라우저로 열면 서버 없이 바로 동작합니다.

## 사용 방법

1. `index.html`을 브라우저로 엽니다.
2. 오른쪽 위 `한 / EN / 日` 버튼으로 한국어·영어·일본어를 바꿉니다. 해 / 달 버튼으로 다크·라이트 테마를 바꿉니다.

전자서명 창에서도 비밀번호에 아무 값이나 넣으면 서명됩니다. 입력한 데이터는 브라우저(localStorage)에만 저장되며, **시스템 설정 관리 > 예시 데이터 초기화**로 처음 상태로 되돌릴 수 있습니다.

## 들어 있는 화면

| 구분 | 화면 |
|---|---|
| Work | 홈(오늘 확인할 일), MBR Creation(작성·검토 상신·시행·폐기), EBR 관리(발행 → 제조 지시 → 설정 → BR 불출 → 생산 → 반납 검토), 공정 POP(Step 진행·기록 시트·실시간 계측·Remark·제조실적·알람 설정), 개별 작업 기록(Logbook 29종), Remarks 관리, 결재 관리(결재·반려·기안회수) |
| Master data | 공통 코드 관리, General Inst 기본값 관리, 제조 지시 알람, 보호구관리, CRA REPORT |
| System | 사용자 관리, 시스템 설정 관리, Sitemap |

MBR 상신 → 결재 승인 → 시행일 지정 → EBR TRANSFER → 발행·불출 → POP 생산 → 반납 검토 → 결재까지 상태가 실제로 이어집니다. 모든 데이터는 예시이며 회사명·실제 인물명은 들어 있지 않습니다.

## 다시 빌드하기

```
python3 build.py
```

| 파일 | 내용 |
|---|---|
| `src/template.html` | 화면 틀과 스타일 |
| `src/app.js` | 화면·예시 데이터·동작 |
| `src/screen_spec.json` | 화면 명세(메뉴, 조회 조건, 버튼, 그리드 열) |
| `src/i18n.json` | 영어·일본어 번역 |
| `src/icons.json` | 아이콘 |
